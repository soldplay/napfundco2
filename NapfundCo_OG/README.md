# 🐾 Napf&Co

**Napf&Co** ist ein moderner E-Commerce Online-Shop für Premium-Tierfutter.

## Was ist Napf&Co?

Eine vollständig responsive Website für den Verkauf von hochwertigem Hunde- und Katzenfutter. Der Shop bietet:

- Übersichtlicher Produktkatalog mit verschiedenen Kategorien
- Interaktiver Futterberater zur personalisierten Empfehlung
- Informative Ratgeber-Artikel zur Tierernährung
- FAQ-Bereich für häufige Fragen

## Rechtliches

Die Website ist DSGVO-konform und barrierefrei nach WCAG 2.1 AA Standard.
